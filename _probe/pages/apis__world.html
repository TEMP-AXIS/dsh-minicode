StopParticleOnPos ​

  • 参数及类型：
    • x:number 坐标x
    • y:number 坐标y
    • z:number 坐标z
    • particleId:number / string 特效ID或路径
    • worldId:number / nil 星球ID
  • 返回值及类型：
    • ret:boolean 是否成功
  • 该方法的其他说明： 停止指定位置的粒子特效（支持传特效ID或路径）
  • 具体使用案例如下：
lua
    local x, y, z = Actor:GetPosition(Player:GetHostUin())

    local result = World:StopParticleOnPos(x, y, z, 1001, WorldId)

SetParticleTransform ​

  • 参数及类型：
    • pos:table 位置（米）
    • particleIdArg:number / string / table 特效ID/路径或数组
    • offset:table / nil 偏移（米）
    • rot:table / nil 旋转
    • scale:table / nil 缩放
    • worldId:number / nil 星球ID
  • 返回值及类型：
    • ret:boolean 是否成功
  • 该方法的其他说明： 调整指定位置的粒子特效偏移/旋转/缩放（支持单个或多个特效）
  • 具体使用案例如下：
lua
    local x, y, z = Actor:GetPosition(Player:GetHostUin())

    -- 设置效果缩放2倍 

    local result = World:SetParticleTransform({x = x, y = y, z = z}, 1001, nil, nil, {x = 2, y = 2, z = 2}, WorldId)

FindCanSpawnMobPosList ​

  • 参数及类型：
    • centerX:number 中心x
    • centerY:number 中心y
    • centerZ:number 中心z
    • radius:number 半径
    • includeCenterPos:bool / nil 是否包含中心点
    • worldId:number / nil 星球ID(默认当前主机所在星球)
  • 返回值及类型：
    • posList:table / nil 位置列表
  • 该方法的其他说明： 获取指定中心点周围，以设置的半径为范围的「可刷怪」位置列表，可选是否把中心点也算进结果里
  • 具体使用案例如下：
lua
    local x, y, z = Actor:GetPosition(Player:GetHostUin())

    local posList = World:FindCanSpawnMobPosList(x, y, z, 10, true, WorldId)

    if posList then

        for i, v in ipairs(posList) do

            print("可以创建生物位置", v.x, v.y, v.z)

        end

    end

FindEcosystem ​

    • radius:number / nil 查找半径

  • 返回值及类型：

  • 具体使用案例如下：
lua
    local x,y,z = World:FindEcosystem(centerX, centerY, centerZ, BiomeType.GrassLand, 50)

    if x and y and z then

        print("找到草原", x, y, z)

    end

GetWorldCreateMobRule ​

  • 参数及类型：
    • biometype:number 地形类型(BiomeType), biometype < 0 返回全部, biometype > 0 返回指定地形BiomeType

  • 返回值及类型：

  • 具体使用案例如下：
lua
local ret = World:GetWorldCreateMobRule(biometype, worldId)
