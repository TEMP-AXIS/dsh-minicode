SetText ​

  • 参数及类型：
    • objid:number 玩家/对象ID
    • uiid:string 界面ID
    • elementid:string 元件ID
    • text:string 文本内容
    • animid:number 动画ID(可选)
    • time:number 动画时长(可选)
    • mode:number 播放模式(可选)
  • 返回值及类型：
    • bool:boolean 是否设置成功
  • 该方法的其他说明： 设置指定文本元件的内容，可选带动画效果（打字机等）
  • 具体使用案例如下：
lua
    local isSuccess = CustomUI:SetText(Player:GetHostUin(),"7482986899365911542-22886","7482986899365911542-22886_2", "测试文本")

GetMonsterObjIcon ​

  • 具体使用案例如下：
lua

    if obj then

        local icon = CustomUI:GetMonsterObjIcon(obj:GetId())

        if icon and icon ~= "" then

            print("获取怪物图标成功")

        end

    end
