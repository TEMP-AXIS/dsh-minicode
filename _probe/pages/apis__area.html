CreateAreaPrefab ​

  • 参数及类型：
    • pos:table 区域底部中心位置
    • size:table 区域大小
    • worldId:number 星球id(默认当前主机所在星球)
  • 返回值及类型：
    • obj:table 区域对象
    • id:number 区域对象ID
  • 该方法的其他说明： 创建区域预制体对象，设置区域大小和位置，返回区域对象和对象ID
  • 具体使用案例如下：
lua
    -- 在玩家位置下方上创建一个20*20*20 尺寸的区域对象， 玩家在整个区域包围盒底面正中心

    local area = Area:CreateAreaPrefab({x = x, y = y, z = z}, {x = 21, y = 21, z = 21}, WorldId)

    --区域对象也是对象，可以挂载组件等

    if area then

        local areaId = area:GetId() -- 获取区域对象的id

        -- area:AddComponent("组件id")

    end

    local startPos, endPos = Area:GetAreaRectRange(area:GetId())

GetAreaUuidByObjId ​

  • 参数及类型：
    • objId:number 区域对象ID
  • 返回值及类型：
    • id:number 区域uuid
  • 该方法的其他说明： 根据区域对象ID获取对应的区域唯一标识符(uuid)
  • 具体使用案例如下：
lua
local id = Area:GetAreaUuidByObjId(objId)

CreateAreaRectByRange ​

  • 参数及类型：
    • posBeg:table 区域起始坐标
    • posEnd:table 区域结束坐标
    • btmp:boolean 是否是临时区域
    • worldId:number 星球id(默认当前主机所在星球)
  • 返回值及类型：
    • id:number 区域ID
  • 该方法的其他说明： 根据起始和结束坐标创建矩形区域，通过范围定义区域边界
  • 具体使用案例如下：
lua
    -- 以玩家为底面中心位置 创建一个矩形区域，指定起始点和终点

    local startPos = {x = x - 10, y = y , z = z - 10}

    local endPos = {x = x + 10, y = y + 20, z = z + 10}

    local areaId = Area:CreateAreaRectByRange(startPos, endPos, false, WorldId)

DestroyArea ​

  • 参数及类型：
    • areaid:number 区域ID
  • 返回值及类型：
    • bool:boolean 是否成功
  • 该方法的其他说明： 销毁指定ID的区域，释放区域资源
  • 具体使用案例如下：
lua
    -- 销毁区域

    local result = Area:DestroyArea(areaId)

  • 参数及类型：

  • 返回值及类型：

GetAreaRectLength ​

  • 参数及类型：
    • areaid:number 区域ID
  • 返回值及类型：
    • lenx:number x轴向长度
    • leny:number y轴向长度
    • lenz:number z轴向长度
  • 该方法的其他说明： 获取指定区域在三个轴向上的长度尺寸
  • 具体使用案例如下：
lua
    -- 获取矩形区域的长度

    local lengthX, lengthY, lengthZ = Area:GetAreaRectLength(areaId)

  • 参数及类型：
    • areaid:number 区域ID
  • 返回值及类型：
    • posBeg:table 区域起始坐标

lua
    -- 获取矩形区域的范围

    local startPos, endPos = Area:GetAreaRectRange(areaId)

ClearAllBlock ​

  • 参数及类型：
    • areaid:number 区域唯一ID
    • blockid:number / string 方块类型ID
    • num:number 最大清除数量
    • btriggerevent:boolean 是否触发事件(默认false)
  • 返回值及类型：
    • bool:boolean 是否成功
  • 该方法的其他说明： 清空指定区域内的所有方块，可指定方块类型和最大清除数量，支持触发事件
  • 具体使用案例如下：
lua
    -- 清除区域内的所有201方块

    local result = Area:ClearAllBlock(areaId, 201)

lua

ReplaceAreaBlock ​

  • 参数及类型：
    • areaid:number 区域唯一ID
    • srcblockid:number / string 区域内的方块类型
    • destblockid:number / string 替换的方块类型
    • face:number 方块朝向
    • color:string / number 颜色
  • 返回值及类型：
    • bool:boolean 是否成功
  • 该方法的其他说明： 将区域内指定类型的方块替换为新的方块类型，支持设置朝向和颜色
  • 具体使用案例如下：
lua
    -- 替换区域内的方块, 200 替换为 203

    local result = Area:ReplaceAreaBlock(areaId, 200, 203)  -- 将方块ID为1的替换为2

FillBlockAreaRange ​

  • 参数及类型：
    • posbeg:table 起始位置
    • posend:table 末点位置
    • blockid:number / string 方块类型
    • face:number 朝向
    • color:string / number 颜色
    • switch:boolean 是否开启
    • filltype:number 填充类型(AreaFillType)AreaFillType
    • worldId:number 星球id(默认当前主机所在星球)
  • 返回值及类型：
    • bool:boolean 是否成功
  • 该方法的其他说明： 用指定方块填充位置范围，支持设置朝向、颜色和填充类型，分帧处理当前帧无法操作填充的方块
  • 具体使用案例如下：
lua
    local startPos = {x = x + 5, y = y, z = z}

    local endPos = {x = x + 6, y = y + 2, z = z + 1}

    -- 填充区域内的方块

    local result = Area:FillBlockAreaRange(startPos, endPos, 105, nil, nil, nil,nil, WorldId)

  • 参数及类型：

DestroyAllBlock ​

  • 参数及类型：
    • areaid:number 区域ID
    • blockid:string / number 方块ID或资产ID
    • n:number 销毁数量(不填或者0则全部销毁)

    • btriggerevent:boolean 是否触发事件
  • 返回值及类型：
    • bool:boolean 操作是否成功
  • 该方法的其他说明： 破坏指定区域内的方块，可指定方块类型、销毁数量、是否掉落物品和是否触发事件
  • 具体使用案例如下：
lua
    -- 销毁区域内的所有105方块

    local result = Area:DestroyAllBlock(areaId, 105)

lua
